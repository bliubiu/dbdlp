7整改建议

  • 优先加密/脱敏高敏感明文字段（11 个）：身份证、银行卡、手机号等明文存储字段建议按分类分级要求改造为加密存储（AES-256-GCM）或展示侧掩码，并收敛访问权限。
  • 重点表治理：BIGTABLE、CUSTOMER、ENTERPRISE、OPENDLP_WIDE、VEHICLE 为高敏感字段集中表，建议核对业务必要性并纳入脱敏改造排期。
  • 复核中风险字段（17 个）：其中「校验通过但列名不吻合」的字段需人工确认是否为真实敏感数据（负样本池类），确认后在控制台标记复核结论。
  • 接入复核流程：在控制台 P07/P08 对台账逐条复核，复核结论写入台账并同步下游治理平台。
