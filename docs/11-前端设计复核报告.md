## 4. 令牌数量与命名分组

**运行时真源 `docs/design-tokens.css`**：456 行 / 15726 bytes，共 **321 处变量声明、311 个唯一变量名**。10 处重复声明全部是刻意覆盖，非冗余：

- `--table-cell-py`、`--table-row-h` 各 4 次：`:root[data-density="compact" / "default" / "comfortable"]` 三档密度覆盖 + 基础声明（`design-tokens.css:317, 421–431`）。
- `--motion-instant / --motion-fast / --motion-base / --motion-slow` 各 2 次：`prefers-reduced-motion: reduce` 下时长归零覆盖（`:445`）。

**构建期真源 `docs/design-tokens.json`**：5 个顶层分组，**314 个叶令牌**：

| 分组 | 叶令牌数 | 对应四层 | 命名职责 |
|---|---|---|---|
| `meta` | 0 | — | 版本、主题、层模型、锁定栈等元信息，不含令牌值 |
| `primitive` | 135 | A1-identity / A1-structure | `--c-*`、`--space-*`、`--text-*`、`--radius-*` 等源值；含 `color / font / text / weight / leading / tracking / space / radius / elevation / zIndex / breakpoint / motion / layout` 13 个子组 |
| `semantic` | 43 | A2 | `--bg / --surface / --fg / --muted / --accent / --success / --warn / --danger / --border` 等语义别名 |
| `component` | 73 | B-slot | `--btn-* / --card-* / --table-* / --badge-* / --input-* / --risk-* / --state-*` 等组件槽位 |
| `extension` | 63 | C-extension | 品牌专属扩展、图表分类色、密度档、掩码与报告专用令牌 |

**命名一致性说明**：JSON 采用短键 + 分组嵌套（如 `primitive.color.bg`、`semantic.accent`），CSS 采用 `--kebab-case` 扁平变量（如 `--bg`、`--accent`）。两者是同一套令牌的两种表示，语义一一对应，非两套令牌；JSON 为构建期真源、CSS 为运行时真源。此差异已登记为遗留风险 R2。

**元信息字段磁盘现值（避免按历史快照误写）**：`lockedStack` / `iconLibrary` / `interfaceContract` / `maskingPolicy` / `reportPolicy` / `errorMessageLanguage` 等契约元信息**仅存在于 `docs/design-tokens.json` 的 `meta` 对象**（共 19 个键），`docs/design-tokens.css` 不含这些键（CSS 只承载变量声明与分组注释）。设计令牌文件磁盘上为 **2 个**（`.css` 运行时真源 + `.json` 构建期真源），`web/app/tokens.css` 是前者的同步副本。此前回传中「五个令牌文件均带这些元信息」属历史快照记忆，已按磁盘现值更正，本报告不作为取值依据。

## 5. 对比度核验结论（WCAG 2.1 AA，正文 ≥ 4.5:1）

按 `docs/design-tokens.css` 的 Primitive 实值（`#FFFFFF / #F7F9FC / #101828 / #344054 / #475467 / #667085 / #1D4ED8 / #B42318 / #067647 / #B54708`）现场复算相对亮度与对比度：

| 前景 / 背景 | 用途 | 实测对比度 | 判定 |
|---|---|---|---|
| `--fg` `#101828` on `--surface` `#FFFFFF` | 主文本 | **17.75:1** | 通过 |
| `--fg-2` `#344054` on `--bg` `#F7F9FC` | 次级文本 | **9.92:1** | 通过 |
| `--muted` `#475467` on `--surface` | 副文本 | **7.69:1** | 通过 |
| `--muted` `#475467` on `--bg` | 副文本（页面底） | **7.29:1** | 通过 |
| `--accent-on` `#FFFFFF` on `--accent` `#1D4ED8` | 主按钮文字 | **6.70:1** | 通过 |
| `--danger` `#B42318` on `--surface` | 危险 / 高风险 | **6.57:1** | 通过 |
| `--success` `#067647` on `--surface` | 成功 / 低风险 | **5.69:1** | 通过 |
| `--warn` `#B54708` on `--surface` | 警告 / 中风险 | **5.43:1** | 通过 |
| `--meta` `#667085` on `--surface` | 三级元数据（≥12px 辅助文字） | **4.97:1** | 通过（全表最低值，仍高于 4.5:1） |

**结论**：9 组全部达到 WCAG 2.1 AA 正文阈值，最低 4.97:1，无失败项。风险四级、任务六态除颜色外均有图标 + 中文文字三重编码，图表图例带文字标签，灰度/打印场景可读；`--border` 对 `--surface` 约 1.5:1 属非文本边框对比，由 3px `--focus-ring` 与可见中文 label 补足，符合 04 §8.2 约定。

**数值偏差（advisory，非阻塞）**：04 §8.2 表内为「约值」（15.8 / 10.9 / 7.5 / 4.6 / 6.7 / 11.0 / 6.3 / 5.9 / 5.4 / 6.6:1），与按 Primitive 实值复算结果存在小幅出入（如 `--meta` 文档 4.6:1、实测 4.97:1；`--fg` 文档 15.8:1、实测 17.75:1）。判定结论一致（全部通过），但建议后续统一按实值更新该表，避免复核时被质疑。本轮遵守「不重写 04 全文」，未擅自改动 §8.2，登记为遗留风险 R3。

## 9. 复核结论

- **P0 三项绝对规则全部通过**：emoji 功能图标 0、紫→粉渐变 0（渐变函数 0 / 禁用色值 0）、AI 模板占位 0；组件层硬编码色值 0（`#fff` / `#000` 例外），令牌定义区字面色值均落在 A1-Primitive 许可范围。
- **八条强制红线全部通过**，含字体冻结、图标系统冻结、可访问交互、四层完整 Design Token。
- **令牌体系**：CSS 311 个唯一变量（321 处声明，10 处为密度档与 reduced-motion 刻意覆盖），JSON 314 个叶令牌分 5 组，四层架构 A1 → A2 → B-slot → C-extension 齐备。
- **对比度**：9 组实算全部 ≥ 4.5:1，最低 4.97:1，通过 WCAG 2.1 AA。
- **实现一致性**：`docs/design-tokens.css` 与 `web/app/tokens.css` 逐字节一致（sha256 相同），经 `globals.css` → `@theme inline` → `layout.tsx` 完整挂载，构建与类型检查均退出码 0。
- **最终门禁复扫**（含本报告自身，共 78 个文件）：`emoji=0 gradient=0 purple_pink=0 template_phrase=0`，`BUSINESS_HARDCODED_HEX=0`、`BUSINESS_NONWHITE_HEX=0`，判定 `P0_VERDICT: PASS`。
- 遗留风险 7 项、需裁决冲突 3 项已如实登记；本轮未关闭任何未决项、未删除任何历史记录、未重新生成令牌文件。
